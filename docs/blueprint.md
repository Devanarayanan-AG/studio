# **App Name**: Campus Navigator

## Core Features:

- Class/Lab Search: Search for a specific class or lab by name or ID.
- Location Finder: Returns the block and floor of the requested class or lab.
- Faculty Information: Display the name of the faculty in charge of the lab or class. Data is stored in Cloud SQL database

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) for a calm and informative feel.
- Background color: Light grey (#F0F0F0) to provide a clean backdrop.
- Accent color: Muted orange (#FFB347) for important details.
- Body and headline font: 'PT Sans', a humanist sans-serif, combining a modern look and a little warmth.
- Use clear and simple icons for classes, labs, and faculty to enhance usability.
- A clean and organized layout with a prominent search bar and easily readable results.
- Subtle animations when displaying search results to provide visual feedback.
